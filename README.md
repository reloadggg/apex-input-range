# Input Range

**Apex 手柄改键与连招训练器**

[在线体验](https://apex.efastt.store/) · [GitHub](https://github.com/reloadggg/apex-input-range) · [MIT License](LICENSE)

**中文** · [English](README.en.md) · [日本語](README.ja.md)

改完键位后，总会下意识按回旧键。Input Range 把跳跃、滑铲、换弹、技能等动作变成浏览器里的按键练习，帮助你熟悉新布局，再把它们连成顺手的操作。

支持 **Xbox、DualShock 4（PS4）、DualSense（PS5）**，界面提供中文、English 和日本語。无需安装或注册，连接手柄即可开始。

## 功能

- **配置导入与前后对照**：读取 Apex 配置，比较新旧键位；没有旧文件也能手动填写。
- **改键专项**：提高常用动作、改动键位和旧键冲突的出现频率。
- **11 组内置连招**：覆盖常用基础、交火衔接和身法按键预习，同页显示完整步骤。
- **混合训练**：自由勾选不同分类的连招，练完一组再随机切换。
- **我的弱项 / 自定义**：自己编排动作顺序、调整每步停顿，单独练习或加入混练。
- **训练记录**：查看正确率、反应时间、旧键误触和连续动作表现，支持导出 JSON。

## 快速开始

1. 用 Chrome 或 Edge 打开 **[apex.efastt.store](https://apex.efastt.store/)**。
2. 通过 USB 或蓝牙连接手柄，保持页面在前台，按一下手柄按键让浏览器识别。
3. 在「键位对照」中导入自己的配置，或手动设置当前键位。**内置布局只是示例，请先换成自己的配置。**
4. 返回训练场，选择连招或训练模式，点击「开始训练」。

暂时没有手柄时，可以在「手柄监视器」开启键盘体验。体验成绩单独标记，不计入手柄每日目标。

## 导入 Apex 键位

Windows 下按 **Win + R**，粘贴以下路径并回车：

```text
%userprofile%\Saved Games\Respawn\Apex\profile
```

将 `profile.cfg` 拖入「改键后」。如果保留了改键前的配置副本，例如 `profile_backup.cfg`，将它导入「改键前」；没有备份可直接手动录入旧键位。检查预览和警告后，再点击应用。

需要补充 `settings.cfg` 或 `settings_backup.cfg` 时，可在这里找到：

```text
%userprofile%\Saved Games\Respawn\Apex\local
```

自定义布局通常需要 `profile.cfg` 才能正确识别，单独的 `settings.cfg` 可能只记录按键槽位。支持标准布局、自定义布局及可识别的直接绑定；不支持或不完整的配置会提示，未识别动作保留原设置。游戏内再次改键后，需要重新导入。

新旧方案都支持手动编辑和手柄单键录入。大招默认按「战术技能 + 标记」生成，也能手动设置为单键或双键组合。

## 怎么练

### 连招与混合训练

| 分类 | 内置练习 |
| --- | --- |
| 常用基础 | 滑铲跳、跳跃接换弹、滑铲接换弹、实战串练 |
| 交火衔接 | 切枪补枪、蹲下换弹再开火、滑铲跳接开火、技能与大招切换 |
| 身法预习 | 蹬墙跳、兔子跳、滑索跳的简化按键练习 |

选择一组后，下方会显示完整动作和当前对应按键。跟随高亮输入，等下一步亮起再按；同一个键连续出现时，需要松开后重新按下。

例如，实战串练的顺序是：

**技能 → 跳跃 → 滑铲 → 射击 → 蹲下 → 射击 → 换弹 → 换枪**

「混合训练」可勾选内置连招和已保存的自定义组。每组等概率抽取，完整练完后再切换；有多组可用时，不会连续重复同一组。停用的组或包含未启用动作的组不会出题。

### 我的弱项 / 自定义

打开「我的弱项 / 自定义」→「新建动作组」，填写名称并选择各步动作。支持添加、删除、上下移动步骤，以及设置每步 **0–1.5 秒**的停顿。每组 **2–12 步**，最多保存 **15 组**。

点击「保存并预览」后，即可开始反复练习，也可以在「混合训练」中勾选它。每一步的物理按键始终跟随你的当前键位。

初始的 5 组是可编辑示例。个人弱项由你自行编排；系统自动生成的是**新旧键位冲突练习**，例如原来的跳键现在负责技能，就生成「跳跃 → 技能 → 跳跃」。训练成绩不会自动修改键位或生成弱项组。

### 单项与改键专项

| 模式 | 练习内容 |
| --- | --- |
| 按键识别 | 看到物理按键提示，找到对应按钮 |
| 动作记忆 | 看到游戏动作，按当前绑定；可开启按键提示 |
| 改键专项 | 按设置的频率混合单动作、连续动作和旧键冲突练习 |

改键专项可调整各动作频率，并对改过的动作加练。自定义组的频率只影响随机专项，不影响混合连招的等概率抽取。

按自动奔跑习惯，**冲刺不参与动作和连招训练**，但键位对照仍保留冲刺绑定。

## 手柄与练习说明

- 支持浏览器提供 `standard` 映射的 Xbox、DS4 和 DualSense。DS4Windows / Steam Input 输出虚拟 Xbox 时，可手动切换 PS 按键显示。
- 只计算新的按下动作，长按不重复计分；双键组合需要同时按住。
- 按错保留当前题目，按对继续。支持 30 / 60 / 120 秒和不限时练习；Esc、切出页面或手柄断开会暂停。
- 背键按其映射的普通按钮识别。摇杆方向、系统键、触摸板、震动和自适应扳机效果不参与训练。
- 连招练习用于熟悉按键顺序与节奏，不模拟地形、移动、武器动画或技能冷却。完整身法需在游戏内练习；参考[连招资料说明](docs/combo-research.md)。

## 数据与隐私

配置文件仅在浏览器内解析，不上传、不执行，也不修改原始游戏文件。网页需要你主动选择文件，不能自动扫描游戏目录，也不会向游戏发送输入。

设置、自定义组和最近 50 轮训练记录保存在当前浏览器。清理浏览器数据、更换浏览器或网址后，记录不会自动同步。可在「训练记录」导出 JSON。

## 本地开发

使用 React、TypeScript、Vite 和浏览器 Gamepad API，无需后端。需要 **Node.js 22.6+**，推荐 **Node.js 24**。

```bash
git clone https://github.com/reloadggg/apex-input-range.git
cd apex-input-range
npm ci
npm run dev
```

打开 **http://127.0.0.1:5173**。

```bash
npm test           # 单元测试
npm run test:e2e   # 浏览器测试（当前配置使用 Microsoft Edge）
npm run build     # 类型、翻译检查与生产构建
```

翻译维护在 `src/locales/messages.tsv`，按中文原文、英文、日文三列填写并保留占位符，运行 `npm run i18n:build` 生成语言文件。
