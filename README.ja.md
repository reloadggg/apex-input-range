# Input Range

**Apex のボタン配置変更・連続操作トレーナー**

[オンラインで試す](https://apex.efastt.store/) · [GitHub](https://github.com/reloadggg/apex-input-range) · [MIT License](LICENSE)

[中文](README.md) · [English](README.en.md) · **日本語**

ボタン配置を変えると、つい以前のボタンを押してしまいます。Input Range は、ジャンプ、スライディング、リロード、アビリティなどをブラウザーで練習し、新しい配置と連続操作に慣れるためのアプリです。

**Xbox、DualShock 4（PS4）、DualSense（PS5）** に対応し、中国語・英語・日本語で利用できます。インストールやアカウント登録は不要です。

## 主な機能

- **設定の読み込みと比較：** Apex の設定ファイルから新旧の配置を比較。手動入力にも対応します。
- **配置変更の練習：** 頻出動作、変更したボタン、旧配置との競合を重点的に練習できます。
- **全11組の連続操作：** 基本、戦闘、移動テクニックの簡易入力を収録し、全ステップを同じ画面に表示します。
- **ミックス練習：** カテゴリをまたいで組を選び、最後まで終えてからランダムに切り替えます。
- **苦手な操作 / カスタム：** 動作の順序と待ち時間を自分で設定し、単独でもミックスでも練習できます。
- **練習履歴：** 正解率、反応時間、旧配置の誤入力、動作間の切り替えを確認し、JSONで書き出せます。

## はじめ方

1. Chrome または Edge で **[apex.efastt.store](https://apex.efastt.store/)** を開きます。
2. USB または Bluetooth でコントローラーを接続し、ページを前面にしたままボタンを押すと認識されます。
3. **ボタン配置**で設定を読み込むか、現在の配置を手動入力します。**同梱の配置はサンプルです。自分の設定に変更してください。**
4. トレーニング画面に戻り、連続操作またはモードを選んで**練習開始**を押します。

コントローラーがない場合は、コントローラーモニターからキーボード体験を利用できます。体験の記録は区別され、コントローラーの1日目標には含みません。

## Apex のボタン配置を読み込む

Windows で **Win + R** を押し、次のパスを貼り付けて Enter を押します。

```text
%userprofile%\Saved Games\Respawn\Apex\profile
```

`profile.cfg` を**変更後**へドロップします。変更前のファイル（例：`profile_backup.cfg`）を保存してある場合は**変更前**へ読み込みます。バックアップがなければ以前の配置を手動入力できます。プレビューと注意事項を確認してから適用してください。

必要に応じて追加する `settings.cfg` / `settings_backup.cfg` は、次の場所にあります。

```text
%userprofile%\Saved Games\Respawn\Apex\local
```

カスタム配置の認識には通常 `profile.cfg` が必要です。`settings.cfg` だけではボタンのスロットしか分からない場合があります。標準配置、カスタム配置、認識可能な直接バインドに対応します。未対応・不完全な設定には注意を表示し、未認識の動作は既存設定を保持します。ゲーム内で配置を変更したら、再度読み込んでください。

新旧の配置は手動編集でき、コントローラーからの1ボタン入力にも対応します。アルティメットは初期設定で**戦術アビリティ＋ピン**から生成し、単独ボタンまたは2ボタン同時押しに変更できます。

## 練習方法

### 連続操作とミックス練習

| カテゴリ | 内蔵の練習 |
| --- | --- |
| 基本 | スライディングジャンプ、ジャンプからリロード、スライディングからリロード、実戦シーケンス |
| 戦闘の連続操作 | 武器切り替えから射撃、しゃがみ・リロード・射撃、スライディングジャンプから射撃、アビリティとアルティメットの切り替え |
| 移動テクニックの予習 | ウォールバウンス、バニーホップ、ジップラインジャンプの簡易入力 |

組を選ぶと、すべての動作と現在のボタンを表示します。ハイライトに従い、次のステップが光るまで待ってから押してください。同じボタンが続く場合は、一度離してから押し直します。

実戦シーケンスの例：

**アビリティ → ジャンプ → スライディング → 射撃 → しゃがみ → 射撃 → リロード → 武器切り替え**

**ミックス練習**では、内蔵の組と保存したカスタム練習を選択できます。各組を同じ確率で選び、最後まで終えてから次の組へ進みます。複数の組が利用可能な場合、同じ組を続けて出題しません。無効な組や無効な動作を含む組は除外します。

### 苦手な操作 / カスタム

**苦手な操作 / カスタム → シーケンスを作成**から、名前と各ステップの動作を指定します。追加・削除・上下移動と、各ステップの待ち時間（**0～1.5秒**）を編集できます。**1組2～12ステップ、最大15組**を保存できます。

**保存してプレビュー**を押すと、単独で繰り返し練習できます。ミックス練習に追加することもできます。各ステップのボタンは現在の配置に従います。

初期の5組は編集可能なサンプルです。苦手な操作は自分で登録します。自動生成するのは**新旧の配置の競合練習**で、以前のジャンプボタンが現在はアビリティなら「ジャンプ → アビリティ → ジャンプ」を生成します。成績に応じたボタン配置の変更や、苦手な操作の自動生成は行いません。

### 単独動作と配置変更の練習

| モード | 練習内容 |
| --- | --- |
| ボタン認識 | 表示された物理ボタンを探す |
| アクション記憶 | 表示された動作の現在のボタンを押す。ヒント表示も可能 |
| 配置変更の練習 | 単独動作、連続操作、旧配置の競合を指定した頻度で混ぜる |

配置変更の練習では動作の頻度を調整し、変更したボタンを重点的に練習できます。カスタムの組の頻度はランダムな配置変更の練習にのみ影響し、ミックス練習では等確率です。

自動スプリントを前提に、**スプリントは動作と連続操作の出題から除外**します。比較表には実際のボタン配置を残します。

## コントローラーと練習の仕様

- Xbox、DS4、DualSense ともにブラウザーの `standard` マッピングが必要です。DS4Windows / Steam Input が仮想 Xbox として出力する場合は、PS 表示を手動で選べます。
- 押した瞬間だけを判定し、長押しで繰り返し加点しません。2ボタン同時押しでは両方を押している時間が必要です。
- 間違えると同じ問題を続け、正解すると次へ進みます。30 / 60 / 120秒または時間無制限を選べます。Esc、画面のフォーカス喪失、切断で一時停止します。
- 背面ボタンは割り当て先の通常ボタンとして認識します。スティックの方向、システムボタン、タッチパッド、振動、アダプティブトリガーは対象外です。
- 連続操作はボタンの順番とリズムを練習するものです。地形、移動、武器アニメーション、クールダウンは再現しません。技の完成はゲーム内で練習してください。[連続操作の調査メモ](docs/combo-research.md)も参照できます。

## データとプライバシー

設定ファイルはブラウザー内で解析し、アップロード、実行、元のファイルの変更は行いません。ファイルは自分で選択する必要があり、ゲームのフォルダーを自動走査したり、ゲームへ入力を送信したりすることはありません。

設定、カスタムの組、直近50回の履歴は現在のブラウザーに保存します。ブラウザーデータの削除やブラウザー・アドレスの変更で、データは自動移行されません。結果を保存したい場合は、履歴からJSONを書き出してください。

## ローカル開発

React、TypeScript、Vite、ブラウザーの Gamepad API を使用し、バックエンドは不要です。**Node.js 22.6以降**が必要で、**Node.js 24**を推奨します。

```bash
git clone https://github.com/reloadggg/apex-input-range.git
cd apex-input-range
npm ci
npm run dev
```

**http://127.0.0.1:5173** を開きます。

```bash
npm test           # 単体テスト
npm run test:e2e   # ブラウザーテスト（現在は Microsoft Edge を使用）
npm run build     # 型・翻訳の確認と本番ビルド
```

翻訳は `src/locales/messages.tsv` の中国語原文・英語・日本語の3列で管理します。プレースホルダーを保持し、`npm run i18n:build` で言語ファイルを生成してください。

不具合の報告は [Issues](https://github.com/reloadggg/apex-input-range/issues) へ、改善は Pull Request で受け付けています。コントローラーの互換性については、機種、接続方法、ブラウザーのバージョンを添えてください。
