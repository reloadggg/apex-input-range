## 落地范围

保留原有的滑铲跳、跳跃换弹、滑铲换弹、用户指定 8 步实战串练。新增：

| 类别 | 练习 | 按键动作 |
| --- | --- | --- |
| 交火衔接 | 切枪补枪 | 射击 → 换枪 → 射击 |
| 交火衔接 | 蹲下换弹再开火 | 射击 → 蹲下 → 换弹 → 射击 |
| 交火衔接 | 滑铲跳接开火 | 滑铲 → 跳跃 → 射击 → 换枪 → 射击 |
| 交火衔接 | 技能与大招切换 | 技能 → 跳跃 → 大招 → 射击 |
| 身法预习 | 蹬墙跳按键预习 | 滑铲 → 跳 → 再按跳 |
| 身法预习 | 兔子跳按键预习 | 滑铲 → 跳 → 跳 → 跳 |
| 身法预习 | 滑索跳按键预习 | 互动 → 跳 → 跳 |

交火四组是针对用户改键冲突自行编排的按键场景，不包装成上述作者推荐的固定战术。身法三组参考玩家教程的主题，使用简化按键预习；页面给出来源、日期和章节链接。

所有组使用当前导入的动作绑定，绝不固定为默认手柄键。练习间隔 0.2–0.45 秒是人为设计的提示节奏，不是游戏动画时间、落地间隔或身法判定窗口。

身法需要速度、地形、摇杆控制、角色姿态与时机；兔子跳还受按住蹲 / 切换蹲设置影响。训练器只检测按下边沿，不检查持续蹲姿、抬键动作本身、摇杆方向或游戏身法成功。连续相同按键必须松开再按才会记下一次。

没有将 Superglide、Mantle Boost / Jump、Tap Strafe 等操作伪装成通用几次按键就能完成的连招。
